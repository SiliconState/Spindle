    Commands

    Threads run bash in a Linux inside this browser (bash, Python, Node, git, curl), sealed off from your computer and from Spindle's keys. It starts with the first command; a thread's commands reach the web only once you turn its network on.

    Network
    Relay

    Without one, a thread with network reaches websites through Chrome (HTTP and HTTPS; no cookies). With a relay you run (a WISP server, such as wisp-js or epoxy-server), its commands reach any address through it: ssh, git over SSH, databases. Names are then looked up over DNS-over-HTTPS (cloudflare-dns.com). Spindle runs no relay of its own.

    Sites scripts may call

    A script can call a site you list here with spindle http URL, whatever its thread's network: journaled like every Spindle call, sent without your cookies. Chrome asks once for each.
