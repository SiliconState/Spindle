CONNECT

Connect {{CLIENT}}?

It gets a token of its own for this host. With it, it may:

  • run commands in this host's sandbox;
  • bring its threads here, run them on this host, and take them back;
  • read this host's providers and models.

It sees none of this host's other threads and cannot change the host. Revoke it any time under Settings, Screens.
